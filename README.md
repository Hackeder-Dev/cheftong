# เชฟโต้งจัดให้ · เว็บไซต์รับจัดเลี้ยง

เว็บไซต์แบบไฟล์ล้วน (static) สำหรับร้าน เชฟโต้งจัดให้ บางคูรัด บางบัวทอง นนทบุรี

- ข้อมูลร้านและข้อความทั้งหมดแก้ได้ที่ `site-config.js`
- รายการภาพเมนูอยู่ใน `data.js` และไฟล์ภาพอยู่ใน `images/`
- เปิดใช้งานบน GitHub Pages: Settings → Pages → Branch: `main` / `(root)` → Save
